# Ejercicios prácticos

20 ejercicios con datos ficticios o sintéticos: entradas, resultados y comprobaciones. Ejecutados mediante el script Python incluido para que puedas repetirlos y estudiar su funcionamiento.

Resultado: 20 de 20 completados correctamente. Consulta `validation-results.json` y `sample-data.json`.

## Repetir

```bash
python validate_scenarios.py
```

Para Mercado Aprende instala primero las dependencias del README. Los ejercicios usan almacenamiento temporal.
